# CyberMentor (FREE) - with 30-day course

Windows (cmd), Ollama:
  set PROVIDER=ollama
  set FAST_MODEL=llama3.2:3b
  python server.py
Then open http://localhost:5000

Gemini instead:
  set GEMINI_API_KEY=your-key
  python server.py

Files: server.py, curriculum.json (edit lessons/resources here), static/index.html
